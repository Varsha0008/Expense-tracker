# Personal Expense Tracker

A command-line Personal Expense Tracker built in Python using **Pandas** and **Matplotlib**. It logs daily expenses into a CSV file (`expenses.csv`), calculates category-wise summaries, and generates visual charts (`expense_charts.png`)—deployed and executed on **Azure Machine Learning**.

## Features
* **Add Expenses:** Record new expenses with date, category, amount, and description.
* **Persistent Storage:** Automatically saves and loads transaction records using `expenses.csv`.
* **Data Analysis:** Summarizes total spending and category breakdowns using Pandas.
* **Data Visualization:** Generates pie and bar charts saved directly to `expense_charts.png`.

## Project Files
* `expense_tracker.py` – Main Python script for logging and analyzing expenses.
* `expenses.csv` – Dataset storing expense records.
* `expense_charts.png` – Output visualization generated by Matplotlib.

## How to Run on Azure Machine Learning
1. Open **Azure Machine Learning Studio** and start a **Compute Instance**.
2. Go to **Notebooks** and open the **Terminal**.
3. Clone this repository and navigate into the folder:
   ```bash
   git clone https://github.com
   cd Expense-tracker
   ```
4. Install the required libraries:
   ```bash
   pip install pandas matplotlib
   ```
5. Run the application:
   ```bash
   python expense_tracker.py
   ```
